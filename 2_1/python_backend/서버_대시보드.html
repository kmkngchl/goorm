🖥️ 내 백엔드 서버

● 서버 실행 중 (http://localhost:5000)

이 서버는 요청을 기다리고 있어요. 브라우저나 다른 프로그램이 문을 두드리면 응답을 줍니다.

🚪 API 문들

서버에 들어갈 수 있는 문들입니다.

GET / 서버가 살아있는지 확인
JSON 응답
GET /api/chats/ 채팅방 목록 보기
방들이 나열됨
POST /api/chats/ 새 채팅방 만들기
방 이름 필요
POST /api/chats/1/messages 1번 방에 메시지 보내기
보내는 사람, 내용 필요

🔄 서버가 작동하는 흐름

1️⃣ 브라우저나 프로그램이 http://localhost:5000/api/chats/ 로 요청을 보냄
2️⃣ 파이썬 서버가 요청을 받고 채팅방 목록을 찾음
3️⃣ 서버가 JSON 형태로 결과를 보냄
4️⃣ 브라우저가 결과를 예쁘게 보여줌

⚠️ 참고

이 파일은 그냥 화면만 보여주는 용도에요. 실제 데이터를 보내고 받으려면 파워셸에서 서버를 켜고 명령어를 입력해야 하지만, 서버가 어떤 생김새인지 확인하는 데 도움이 될 거예요.
